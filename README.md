# Codswallop

A VSCode extension that detects "vibe coding" - when students blindly accept AI-generated code without understanding it - and creates personalised comprehension quizzes to ensure genuine learning.

## Overview

Codswallop monitors coding patterns to identify potential AI-assisted code that may not be fully understood. When suspicious patterns are detected, it generates context-aware quizzes ("vibechecks") using Claude AI to verify comprehension. Teachers can monitor student progress through a real-time dashboard.

## Features

### Vibe Detection

The extension monitors three key indicators:

| Indicator | Threshold | Description |
|-----------|-----------|-------------|
| Line Spike | >50 lines/min | Rapid code additions (e.g., pasting large blocks) |
| High Complexity | >20 cyclomatic | Complex functions that may be copy-pasted |
| Paste Detection | >10 lines | Direct paste operations |

When any threshold is exceeded, a clickable CodeLens appears above the code with the option to "Take Quiz".

### Animated Vibe Character

An animated detective-style blob companion that reacts to your coding:
- **Idle**: Gently floating with subtle animations
- **Watching**: Alert eyes tracking code changes
- **Detecting**: Suspicious squint with magnifying glass
- **Questioning**: Thoughtful pose during quizzes
- **Celebrating**: Star eyes and confetti when you pass
- **Concerned**: Encouraging expression when you need more practice
- **Sleeping**: Zzz floating after inactivity

### AI-Powered Quizzes

Quizzes are generated by Claude AI and focus on:
- **Line Spike**: Control flow, edge cases, variable scope
- **High Complexity**: Branching logic, loop conditions, error paths
- **Paste Detection**: Overall logic, data flow, API contracts

Pass threshold: 75%

### Teacher Dashboard

Real-time Next.js dashboard showing:
- Live activity feed
- Student leaderboard
- Analytics and trends
- Classroom management

## Installation

### Extension (Development)

```bash
cd extension
npm install
npm run compile
```

Press **F5** in VSCode to launch the extension in debug mode.

### Extension (Package)

```bash
cd extension
npm run package
```

This creates `codswallop-0.1.0.vsix` which can be installed via:
- VSCode Command Palette: "Extensions: Install from VSIX..."

### Dashboard

```bash
cd dashboard
npm install

# Terminal 1: Start Convex backend
npx convex dev

# Terminal 2: Start Next.js frontend
npm run dev
```

Visit `http://localhost:3000` for the teacher dashboard.

## Configuration

Configure via VSCode Settings (`Ctrl+,`):

| Setting | Default | Description |
|---------|---------|-------------|
| `codswallop.enabled` | `true` | Enable/disable vibe detection |
| `codswallop.thresholds.complexity` | `20` | Cyclomatic complexity threshold |
| `codswallop.thresholds.lineSpike` | `50` | Lines per minute threshold |
| `codswallop.thresholds.pasteLines` | `10` | Pasted lines threshold |
| `codswallop.debounceWindow` | `60000` | Cooldown (ms) before re-triggering |
| `codswallop.convexUrl` | `""` | Convex deployment URL |

## Commands

Access via Command Palette (`Ctrl+Shift+P`):

- **Codswallop: Start Vibecheck** - Manually trigger a quiz
- **Codswallop: Show Detections** - View current detections
- **Codswallop: Open Dashboard** - Open teacher dashboard
- **Codswallop: Set Anthropic API Key** - Configure AI access
- **Codswallop: Show Vibe Character** - Display the animated companion
