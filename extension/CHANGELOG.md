# Changelog

All notable changes to the Codswallop extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-01-01

### Added
- Initial release of Codswallop
- Vibe detection for line spikes (>50 lines/min)
- Vibe detection for high cyclomatic complexity (>20)
- Vibe detection for large paste operations (>10 lines)
- AI-powered comprehension quizzes using Claude
- Animated Vibe character companion with reactive states
- CodeLens integration for triggering vibechecks
- Classroom join functionality for students
- Convex backend integration for data sync
- Teacher dashboard integration
- Support for TypeScript, JavaScript, and Python
